# Security Policy

## Supported versions

`ai-operating-model` ships documentation, skills, and templates (Markdown) — it contains no executable
code. Security-relevant fixes are applied to the current released version.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.0   | :white_check_mark: |

## Reporting a vulnerability

If you find a security-relevant issue — for example, guidance that could lead a consuming project to
leak secrets or mishandle credentials — please report it privately rather than opening a public issue.

Use GitHub's **[Report a vulnerability](https://github.com/arvindcalyx/ai-operating-model/security/advisories/new)**
(the repository's *Security → Advisories* tab) to open a private advisory. Include what you found and
how to reproduce or apply it.

You can expect a best-effort acknowledgement. Non-sensitive questions belong in a normal GitHub issue.
